[knowledge base's guides section](https://github.com/OmniNode-ai/knowledge-base/tree/main/guides)

## Still in this repo

[Infisical Secrets](INFISICAL_SECRETS_GUIDE.md) is deliberately **not yet
migrated** — its entire subject is the org's secrets-manager secret-handling
flow, which the knowledge base's sanitization guard forbids naming and which
matches the knowledge base taxonomy's own restricted-content test. It needs
classification into the knowledge base's private/restricted tier (or a
public-safe rewrite) before it can move.
